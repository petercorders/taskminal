# 26단계 — 대화 중심 전환 · 가독성

사용자 결정(2026-11-12): "chat 모드 왜 개발 안했고 그리고 셀은 왜 있어야 하며 가독성은 왜 이렇게 안좋아" → 고른 것 **대화 중심으로 전환** · **가독성 직접 재고 고치기**, 이어서 "보이게 해주고 Orca 좀 제대로 봐봐 거기 UI/UX 잘 되어 있잖아".
원인: `docs/plan.md` 가 '터미널 앱 + 대화 pane(⌘P 로만 열림)' 으로 세워져 사용자가 기대한 대화 모드와 어긋났고, 화면은 기능 시험만 하고 가독성을 잰 적이 없었다.
브랜치 `stage-26-chat-first`. 커밋은 26a(대화 여는 길) → 26b(대화 중심) → 26c(가독성) 로 나눈다.

plan-check: 서버 없음 — 로컬 화면 · 저장 파일 · 로컬 프로세스(셸 · 에이전트)만 바꾼다.

### 가독성 — 기준과 고칠 것

측정 시험 `tests/e2e/readability.spec.ts`: 화면(사이드바 · 터미널 · 빈 대화 · 대화 · 팔레트 · 설정 · 새 일감 · 일감 없는 첫 화면)마다 보이는 글자를 모두 재서 기준 밖이면 실패. 끈 컨트롤 · 터미널 글자(xterm)는 뺀다.
기준: 대비 4.5:1(큰 글자 3:1) · **모든 글자 12px 이상** · 대화 · 대화상자 본문 14px 이상 · 여러 줄 글 줄 간격 1.4 이상.

전(2026-11-12, 기준 11px 로 잰 첫 판) — 걸린 것: 팔레트 종류 표지 10px(27곳) · 사이드바 '방금' 10px · 대화 배지 'Claude' 10.5px · 마지막 줄 '✓ 안녕' 대비 3.27 · 새 일감 '⌥1' 대비 3.41 · ⌘↩ 키 대비 3.93 · 여러 줄 안내 줄 간격 1.2(빈 대화 · 설정 설명). CSS 의 글자 크기 분포: 11px 66 · 12px 63 · 10px 14 · 10.5px 7 · 11.5px 6 · 13px 10.

고칠 것:
- 글자 크기 한 단계씩: 10 · 10.5 · 11 → 12, 11.5 → 12.5, 12 → 13, 12.5 → 13.5, 13 → 14(본문). 15 · 16 · 20 · 22 은 그대로.
- `--muted` 를 어두운 모양에서 `#a1a6ae` 로(바탕 대비 ≥ 7), `--dim-opacity` 0.62 → 0.82(흐린 글에 곱하는 값).
- 여러 줄 설명 줄 간격 1.45.
- 측정 기준을 12px 로 올려 다시 나빠지면 시험이 실패하게.

## 앱 종료 4경로 · 사라지는 대상

- 새 일감의 대화 pane 은 21단계 대화 pane 과 같다 — 앱 종료 · 창 닫기 = claude/codex 끝(다음 보내기에서 이어 함), 새로 고침 · 렌더러 충돌 = main 의 어댑터는 살아 있고 창이 기록을 다시 그림. 바뀌는 것 없음.
- ⌘J 로 꺼낸 셸은 보통 터미널 pane — 셸 지킴이(16)에 산다.
- 대화상자 '시작' 값은 연 순간의 설정으로 채우고, 만들 때 고른 값을 쓴다. 대화상자가 열린 사이 설정이 바뀌어도 고른 값이 이긴다.
- ⌘J 를 누른 사이 그 탭이 닫히면: 활성 탭을 다시 찾고 없으면 아무 일 없음(reducer 가 없는 탭이면 같은 상태).

## 결과를 모를 때 · 이중 입력

- ① 결과를 모를 때: 서버는 없고, 새 대화 일감에서 claude/codex 를 못 띄우면(설치 · 로그인 없음) 21 · 22단계 대화 pane 의 설치 · 로그인 띠가 그대로 뜬다 — 일감은 만들어져 있고 ⌘J 로 셸을 꺼내 직접 설치 · 로그인할 수 있다. e2e: 없는 에이전트 경로로 새 대화 일감 → 띠 + ⌘J 셸.
- ③ 이중 입력: '만들기' 를 두 번 눌러도 일감은 하나(대화상자가 첫 번에 닫힘 — 12단계 그대로, e2e 로 다시 확인). ⌘J 를 빠르게 두 번 = 꺼내고 되돌아옴 — 셸 pane 이 둘 생기지 않는다(두 번째는 있는 셸을 찾는다). e2e 로 세 번 눌러 셸 pane 수 1.

## 하지 않는 것

- 셸을 숨긴 채 살려 두는 서랍(가리기) — 꺼낸 셸은 보통 pane 이고 ⌘W 로 닫으면 끝난다.
- 탭 이름을 첫 메시지로 짓기 · 모델 pill · @ 파일 · / 명령 · 상태 줄 사용량(27 감사에서 다시 본다).
- 저장소/워크트리 중심 모델로 바꾸기(Orca 의 프로젝트 › 워크스페이스) — 일감 모델은 그대로.
- 옛 일감을 대화 일감으로 바꾸기.

## 계획과 다르게 한 것
- 셸 꺼내기 키 ⌃\` → **⌘J**: 단축키 표(`isAccel`)가 ⌘ 없는 키를 받지 않는다. 대화 입력칸에서도 ⌘J 만은 앱이 받는다(다른 ⌘ 키는 칸의 몫 그대로).
- `start` 가 없으면 셸: CLI(`taskminal new`) · 옛 호출이 말없이 대화로 바뀌지 않게. 기본값 대화는 대화상자가 설정을 넘겨서 정한다.
- 없는 에이전트 경로를 직접 주면 띠가 '못 찾음' 이 아니라 '끝남(crash)' 으로 뜬다 — e2e 는 둘 다 받는다(띠가 뜨고 ⌘J 가 되는 것이 요점).
- 기존 e2e 의 seed 설정은 `newTaskStart: 'terminal'`(helpers) — 대화 시작은 chat-first.spec 이 본다.
- 빈 화면: '새 일감 · Claude 대화로 시작 ⌘N'(주) + '터미널로 시작'(보조).
