## 1. 상태 옮기기 ⌃⌘← / ⌃⌘→

- 화면: 바뀐 뒤 알림 "‘이름’ → 진행 중" (끝이면 "이미 마지막 상태예요"). 묶음 보기에서도 같은 키가 된다(상태는 보기와 상관없는 값).
