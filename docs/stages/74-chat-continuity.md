# 74단계 — Claude 대화 인계와 수동 휴면

Orca 따라잡기 제안의 7번과 10번을 로컬 구조화 대화 화면에서 제공한다.

- Claude 대화에서 **Codex로 인계…**를 열면 가려진 최근 요청, 현재 Git 작업 트리의 변경 파일, 대화 상태와 최근 답변을 담은 초안이 열린다. 이전 답변의 검사 주장은 대화 발췌로 표시한다. 대표 검사 명령과 실제로 받은 도구 결과를 과거 기록으로 보여 주며 현재 커밋의 검증 상태는 미확인으로 시작한다. 변경 목록을 읽지 못하면 초안에 미확인으로 표시한다.
- 사용자가 초안을 고친 뒤 **Codex 입력칸에 넣기**를 누르면 같은 일감과 폴더에서 새 Codex 탭을 연다. 원래 Claude 대화와 기록은 보존된다. Codex에 보낼 때는 새 대화에서 사용자가 전송한다.
- 세션 ID가 있는 완료된 대화에서 **대화 휴면**을 누르면 실행 중인 프로세스의 종료를 확인하고 기록에 휴면 상태를 남긴다. 현재 턴, 하위 에이전트 작업, 질문 응답, 되감기로 갈라질 세션, 아직 보내지 않은 입력·첨부·대기열은 보호한다.
- **휴면 풀기**로 휴면 기록을 해제하면 다음 메시지를 기존 세션 ID로 이어 보낸다. 해제만으로 공급자에 새 메시지를 보내거나 프로세스를 띄우지 않는다. 해제가 완료되기 전의 전송과 다른 세션 ID의 재시도는 거절한다. 일반 셸과 작업 흐름이 관리하는 대화는 대상에서 제외한다.

## 처리와 복구

plan-check: 서버 없음 — 기존 로컬 Git 작업 트리와 가려진 대화 기록을 읽으며 프로세스 종료·재개와 휴면 기록은 로컬에서 처리한다.

- 인계를 취소하거나 탭을 떠나면 편집 중인 초안이 사라진다. 전환이나 확인 중 일감, 원래 대화, 폴더가 바뀌면 제출할 때 다시 찾아 확인하고 대상이 사라지면 입력을 유지한다.
- 휴면 중 같은 버튼의 이중 입력과 새 턴을 막는다. 종료가 확인되지 않으면 프로세스의 종료 알림이 도착할 때까지 새로 띄우지 않는다. 결과를 모를 때는 상태 확인 실패를 표시하며, 다시 시도는 원래 대화에서 시작한다.
- 앱 종료·창 닫기·새로고침·렌더러 충돌 뒤에는 가린 기록과 이미 반영된 휴면 상태를 다시 읽는다. 해제를 기록한 뒤 앱을 종료해도 다음 메시지가 같은 세션을 사용한다. 인계 편집창과 초안은 일시적인 입력 상태다.
- 휴면은 기존 에이전트 프로세스가 유지하던 일회성 실행 상태를 정리한다. 앱은 화면 기록과 공급자가 발급한 세션 ID를 보존한다.

- `tests/unit/chat-handoff.test.ts`에서 마스킹, 최근 목표, 변경 목록 중복 제거, 대화와 검사 상태의 분리를 확인한다. `tests/unit/store.test.ts`에서 새 Codex 탭이 원래 대화의 작업 폴더를 사용하고 기존 pane을 보존하는지 확인한다.
