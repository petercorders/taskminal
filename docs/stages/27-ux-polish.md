# 27단계 — UX 감사 · 다듬기

사용자(2026-11-12): "전부 확인해보고 우리 UI/UX 확인해서 미숙한 부분 제대로 진행해줘". 26단계(대화 중심 · 가독성) 바로 뒤.

## 방법
- 임시 `TASKMINAL_USER_DATA` 로 앱을 띄워 화면 30장을 자동으로 찍었다(둘러보기 스크립트는 저장소 밖 scratchpad `ux27/tour.mjs` — 시험이 아니라 감사 도구라 넣지 않음).
  - 화면: 첫 실행 · 일감 없음 · 빈 대화 · 허락 카드 · 질문 카드 · ⌘J 셸 서랍 · 변경 검토 · 터미널 탭 셋 · Codex 대화 · 팔레트(빈 · 찾기) · 새 일감(기본 · 템플릿) · 설정 10칸 · 명령 기록 ⌘Y · 모든 출력 찾기 · 주간 정리 · 보관 알림(되돌리기) · 보관함 · 원격 끊김 띠.
  - 빠진 화면: 사이드바 '묶음' 보기(둘러보기 스크립트가 단추를 못 찾음 — 앱 문제 아님, 26단계까지 e2e 가 본다).
- 기준(8개, 각 10점): 첫인상 · 정보 구조 · 위계/글자 · 상호작용 피드백 · 일관성 · 빈/오류 상태 · 키보드/접근성 · 밀도/여백. 비교 기준은 26단계 '참고: Orca' 표와 디자인 보드.
- 수정 · 재채점은 두 번까지(토큰 비용 지시).

## 계획과 다르게 한 것
- 주간 정리의 대화(#9)는 고치지 않았다 — 대화 활동이 주간 정리 원천(`src/shared/weekly.ts`)에 없다. 원천을 만드는 일은 기능이라 다듬기 범위 밖.
- 둘러보기 스크립트는 저장소에 넣지 않았다(감사 도구). 고친 것마다 시험을 따로 두었다.

## 하지 않은 것
- 주간 정리에 대화 시간 · 수(#9), `app.close()` 지연(#10) 원인.
- 사이드바 대화 일감의 둘째 줄 글꼴: 마지막 대화 글도 고정폭 글꼴(`task-last`)로 보인다 — 명령과 대화를 가르는 값이 활동에 없어 두었다.
