## c — 결과가 달라지는 드문 경로
- `~//x`: `resolve(homedir(), '/x')` 를 쓰던 5곳(파일 · 편집기 · 작업 흐름 작업 공간 · 작업 공간 IPC · 이슈 준비)은 `/x` 로 풀었다 → 이제 홈 아래 `x`(셸 · git · 나머지 곳과 같은 규칙).
- `~/a/../b`: `realpath` 로 바로 넘기는 3곳(파일 · 편집기 · 작업 흐름 작업 공간)은 `..` 를 글자로 접지 않고 실제 경로로 푼다 — 홈이 심볼릭 링크일 때만 다르다.
- 둘 다 일감 폴더를 그렇게 쓴 경우뿐이고, 새 규칙이 셸을 여는 폴더와 같다.
