부모가 캡처를 직접 열었다. 도구 줄은 실제 높이를 측정하는 기존 배치를 유지해 새 단추가 줄을 바꿔도 패널 머리가 맞는다. 원격 패널의 control은 폭을 줄일 수 있게 하고 경로는 줄바꿈한다. 640×480/200% 검사에서 숨긴 기존 탭 단추가 문서 폭을 4px 넓힌 것을 실제 geometry로 찾아 `overflow:clip`으로 고쳤다. 전송·중단 단추까지 스크롤할 수 있고 가로 overflow가 없음을 e2e로 확인했다.

44~48에서 발견한 HIGH는 입력값 수집/캡처, 병렬 attempt 경합, 서버 중복 소유, 대기 후 cwd 변경, 종료 PID 재사용이었다. 모두 회귀 시험·정확한 변이·관련 재검증으로 처리했다. MEDIUM의 숨겨진 조회와 잘못된 원격 응답도 수명 경계·schema 검증으로 수정했다. VoiceOver·실제 Retina/IME·키보드만으로 원격 전 기능을 잇는 과업·다른 OS GUI·실제 공급자 계정/원격 호스트는 별도 확인이다. 원격 터미널은 줄 입력 콘솔이며 전체 TUI와 네이티브 모바일 앱은 범위 밖이다.

## GC 결과

각 단계 문서에 GC를 남겼으며 전역 진단은 읽기 전용으로 실행했다. 마지막 `/tmp/taskminal-48-gc.json`: eden72/survivor28/cold12/promoted6, 승격 후보r89439e·병합0·규칙 감사17. 후보의 판단은 이번 정확한 변이13개(44:3·45:3·46:2·47:2·48:3)로 도구화했으므로 새 전역 문장·자동 승격은 하지 않았다. rd0536c의 과거 승격 후 재발11회는 이번 작업에서 추가한 기록이 아니다.

이번 실제 정정은 API 기대 목록 갱신 누락, 잘못된 rg가 파일 생성을 건너뛴 도구 실행, 실패 PNG가 통과 증거를 덮은 이름 충돌, 테스트의 셸 echo/옛 locator/잘못된 종료 이벤트였다. 각각 기존 타입/보안 검사 유지, 실제 파일 확인, green 증거 별도 보존, 실제 파일 결과·현재 창·정확한 이벤트로 바꿨다. 더 강한 규칙 문장 대신 실행 가능한 검증을 유지한다.

독립 UI/통합 worker와 읽기 전용 보안 리뷰 worker를 사용하고, 부모가 저장·동시성·원격 서버와 통합을 검토했다. 공유 파일 편집은 순차로 조정했으며 Git index의 단계별 고정 tree를 임시 디렉터리에서 검사해 다음 단계 변경이 이전 검증에 섞이지 않게 했다. 실제 모델은 상속 기본값이고 전체 토큰·금액은 제공되지 않아 미측정이다. 더 싼 모델과 동등 품질이나 최적 비용을 주장하지 않는다.

최종 통합 전체: 타입·경계·단위1,206·e2e341 통과, 패키지 전용2 skip, 종료0. 근거 `/tmp/taskminal-48-full.log`. 마지막 GC도 읽기 전용으로 다시 실행해 같은 후보/상태를 확인했다. 기능 브랜치에만 커밋/push하며 main 병합·새 릴리스는 별도 요청이다.
