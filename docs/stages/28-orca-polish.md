## 계획과 다르게 한 것
- Orca 대화 화면의 실측은 못 했다 — 창이 Codex TUI 였다. 소스의 클래스 → px 로 기준을 잡았다.
- 글 칸 폭은 Orca 기본(46rem = 736px)이 아니라 26단계에서 정한 760px 그대로.
- 대화 머리도 글 칸에 맞췄다(사용자 지시 — Orca 의 머리 줄은 전체 폭).
- 2px 반 칸을 척도에 뒀다(4px 배수가 아니다).
- 모서리는 `--r-sm 5 · --r-md 7 · --r-lg 11`: border-radius 90곳(3~5 → sm, 6~8 → md, 10 · 12 → lg)을 옮겼다. 알약 모양(9 · 11px)과 원(50% · 999px)은 그대로 둔다.
- 찾기 결과가 없을 때의 안내는 CSS `:has()` 로 숨기던 것을 JS 로 바꿨다 — 줄이 묶음 카드 안으로 들어간 뒤 줄이 다 빠져도 Chrome 이 다시 계산하지 않아(`getClientRects` 0 · computed display block) 안내가 안 떴다(`settings.spec:69` 가 잡음). 28c 에서 묶음 · 절 숨김까지 줄 수 세기로 옮겼다(아래 리뷰 절).
- 가독성 시험은 설정 칸의 12px 묶음 제목(`p`)을 '본문 12px' 로 잡았다 — 제목 · 묶음 설명은 `div`(보조 글)로.
- 고치지 않음: 단추 높이 통일(`.button` · 작은 단추 · 사이드바 아래 단추 26px) · 사이드바 일감 줄 높이(내용에 따라 54 · 75 — 줄 수가 다름).
