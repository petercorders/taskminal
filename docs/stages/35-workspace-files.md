# 35단계 — 파일 탐색·미리보기·대화 맥락

승인 계획: `~/.claude/plans/taskminal-orca-five-areas-2026-11-13.md`.

## 구현

- 활성 일감 루트의 폴더 열기·상위 이동·현재 폴더 파일명 필터·새로고침·경로 복사·외부 편집기 열기.
- main이 realpath·상대 경계·민감 파일·파일 크기를 검사한다. .git·node_modules·인증 파일은 목록/내용에서 제외한다.
- 읽기 직전 O_NOFOLLOW, 열린 fd와 전후 파일의 dev/ino, 루트를 다시 검사한다. 검사 후 symlink를 바꾸는 경합을 차단한다. 읽기 버퍼도 상한을 둔다.
- 텍스트 2 MB, 그림·PDF 10 MB 미리보기. 텍스트는 가린 뒤 줄 번호·첨부 범위를 표시한다. Markdown은 안전한 텍스트 기반 제목·목록·본문 미리보기와 소스 전환을 제공한다. 임의 HTML은 실행하지 않는다.
- 그림은 미리보기와 기존 이미지 첨부 계약을 사용한다. 대화 첨부는 기존 5 MB/4장 한도를 지키고 초과를 안내한다.
- PDF.js 6.5.438을 필요할 때 불러와 로컬 worker/canvas로 페이지를 표시한다. PDF JavaScript·액션을 실행하지 않고 XFA를 비활성화한다. 원격 iframe이나 플러그인 권한을 열지 않는다.
- 첨부는 확인한 내용의 스냅샷·범위·SHA-256 표지에 고정한다. 보내기 전 파일 표지가 달라졌으면 다시 확인하게 한다. 40,000자 이상 범위는 줄이도록 안내한다.
- 텍스트는 내용, 그림은 이미지, PDF·바이너리는 '내용 미전달' 파일 참조로 구분한다. 대화 입력에 넣은 뒤 사용자가 보낸다.
- 파일을 대화로 끌면 경로 참조를 넣고 내용은 전달되지 않았음을 설명한다. 내용을 보내려면 파일을 열고 범위를 확인한다.

## 검증

- `tests/unit/workspace-files.test.ts`: 실제 파일·심볼릭 링크·상위 경로·민감 이름·크기·비밀값 가림·변경 표지.
- `tests/unit/workspace-file-race.test.ts`: 정상 검사 후 실제 파일을 외부 symlink로 교체해도 읽기가 거절되는지 확인.
- `tests/e2e/workspace-tools.spec.ts`: Markdown 표시→줄 범위→대화 초안, 확인 후 파일 변경 차단, PDF worker 실제 페이지 표시→참조 첨부.
- PDF 근거: https://mozilla.github.io/pdf.js/examples/ 와 설치 타입. 운영 의존성 npm audit는 취약점 0개였다.
- 실제 사용자 폴더는 읽지 않고 모든 검증은 임시 일감·userData에서 수행했다.

## 수명·한계

- 파일/일감/폴더가 바뀌거나 화면을 닫으면 세대를 올려 이전 읽기 결과를 버린다. 조회 실패 때 기존 작업 폴더·입력을 보존하고 새로고침할 수 있다.
- 앱 종료·창 닫기·새로고침·충돌 때 미전송 파일 내용/그림은 저장하지 않는다. PDF worker·렌더 작업은 정리한다. 기존 대화/터미널 수명은 유지한다.
- 파일 편집·원격 파일 탐색·전체 프로젝트 본문 검색·완전한 CommonMark 렌더링은 제공하지 않는다. 현재 폴더 목록은 1,000개까지이며 대규모 저장소는 폴더를 나눠 탐색한다.
- 외부 열기는 open -t로 편집기를 지정해 .command 실행을 피한다. 기본 프로그램 실행 API는 열지 않는다.
- 패키징한 .app에서도 PDF worker의 실제 페이지 렌더링과 참조 첨부를 확인했다. 실제 IME·Retina·VoiceOver·실제 계정으로 첨부 전송은 미검증이다. 통합 결과는 개발 진행 문서에 기록한다.

## 통합 보강

- 텍스트는 시작 줄부터 2,000줄 단위로 표시하고 시작 줄 변경으로 다음 범위를 읽는다. 첨부는 2,000줄/40,000자까지다.
- PDF canvas는 배율 2·폭 800·높이 4,000, 디코드 이미지 16,000,000px로 제한한다.
- 파일 텍스트와 웹 요소/캡처 URL은 main의 현재 사용자 지정 비밀값·허용값 설정으로 가린다. 파일 미리보기→초안과 웹 요소 확인 경로를 e2e로 검증하고 가림 옵션 제거 변이도 검출했다. 그림 자체의 내용은 자동 가림 대상이 아니므로 전송 전에 확인한다.
