# 75단계 — 워크트리와 PR 검토 도구

Orca 비교에서 정한 3·4·5·6·8번의 첫 버전이다.

| 아이디어 | 진입점과 동작 |
| --- | --- |
| 3. 에이전트 결과 비교 | 워크트리 관리에서 같은 요청을 맡긴 두 워크트리를 고른다. 공통 조상 또는 직접 입력한 시작 SHA를 기준으로 변경 파일과 이름 변경을 나란히 본다. 양쪽에 72단계 JSON을 붙이면 보고서가 가리키는 커밋과 검사 결과를 비교할 수 있다. 요청이 동일했는지는 사용자가 정하며 확인되지 않은 결과는 출처와 함께 표시한다. |
| 4. 충돌 미리보기 | 같은 화면에서 두 커밋의 병합 충돌 예상 경로를 확인한다. 변경 파일 목록은 선택한 시작 SHA를 사용하고, 충돌은 Git의 실제 merge-base 규칙을 사용한다. Git 객체는 임시 저장소에만 쓰고 비교 대상의 인덱스·브랜치·작업 파일은 바꾸지 않는다. 설치된 Git에 `merge-tree --write-tree`가 없으면 충돌 미확인으로 표시한다. 목록은 각 250개까지 표시한다. |
| 5. 환경 준비 상태 | 기존 환경 미리보기에서 끊긴 대상 링크를 표시한다. `.taskminal/environment.json`의 선택 필드 `requiredPaths`에 필요한 상대 경로를 넣고, `ports`에 확인할 TCP 포트를 적는다. 예를 들어 `{"copies":[],"commands":[],"requiredPaths":[".env","node_modules"],"ports":[3000,5173]}`를 쓸 수 있다. 포트를 점유한 프로세스의 관측 결과는 참고 정보다. Windows에서는 포트 미확인으로 표시한다. |
| 6. 전후 캡처 | 앱 브라우저에서 화면 캡처를 한 뒤 변경 전·후 슬롯에 보관한다. 두 장을 옆에 두고 쿼리를 뺀 URL, PNG 픽셀 크기, 브라우저 테마 설정, 확대 비율, 일감 HEAD의 같음·다름·미확인을 읽는다. 브라우저 패널을 열어 둔 동안만 보관한다. 일감 HEAD는 실행 중인 서버가 실제로 제공한 코드 버전과 다를 수 있다. |
| 8. 저장소 간 PR 순서 | GitHub PR 패널에 선행 PR부터 주소를 한 줄씩 입력하고 상태를 읽는다. 순서와 URL은 로컬에서 일감별로 남긴다. 선행 PR의 병합과 체크 통과를 둘 다 확인하지 못하면 뒤의 PR에 검토 보류를 표시한다. PR 상태는 사용자 조회 시점 기준이다. |

## 검증 경로

- `tests/unit/worktree-comparison.test.ts`는 실제 임시 Git 저장소에서 독립 변경, 같은 파일 충돌, 이름 변경, 잘못 고른 기준, 원본 인덱스·Git 객체·미커밋 파일 보존을 확인한다.
- `tests/unit/development-tools.test.ts`와 `tests/unit/configured-ports.test.ts`는 필요한 경로의 누락과 끊긴 링크, macOS의 로컬 TCP 수신 상태를 확인한다.
- `tests/unit/browser-capture-comparison.test.ts`는 캡처 조건의 다름·미확인과 한쪽 사진의 교체를 확인한다.
- `tests/unit/pr-dependencies.test.ts`는 서로 다른 저장소 조회, 반환 대상 검증, 실패·미확인·아직 병합하지 않은 선행 PR이 뒤 항목에 표시되는 것을 확인한다.

## 결과와 미확인 범위

- 타입 검사, 아키텍처 경계 검사, Vitest 144파일·1,743개를 통과했다. E2E 미실행 종료 코드는 4다. 앱 빌드 및 문서 경로 검사를 통과했다. 사용자 지정 기준 검증, 충돌 판독, 끊긴 길, 캡처 미확인, 선행 체크 조건 변이 5개를 모두 검출했다.
- 임시 사용자 데이터의 macOS 앱에서 워크트리 비교 입력을 열어 1200×800 다크 창에서 레이블과 줄 배치를 봤다. GitHub PR 패널에서 공개된 두 PR 주소를 입력하고, 병합은 됐지만 체크가 확인되지 않은 선행 PR을 뒤 항목에 검토 보류로 표시하는 것을 직접 확인했다.
- UI/UX는 부분 검증이다. 워크트리 선택 팝업 때문에 비교 실행은 임시 저장소 단위 시험에서 확인했다. 브라우저 캡처 두 장의 실제 픽셀 대조, 라이트·최소 크기·보조기술 확인은 남아 있다.
