## 2. 원격 (25b)

| 할 일 (보드) | 이렇게 |
|---|---|
| 모델 | `Task.host?: string`(~/.ssh/config Host 이름이나 user@host) · `Task.remoteTmux?: boolean`. 원격 일감의 cwd · pane cwd 는 그 호스트의 경로. 새 pane 은 일감의 host 를 따른다 |
| 원격 pane | main `spawn` 이 `opts.remote = { host, tmux }` 를 받으면 `/usr/bin/ssh`(시험은 `TASKMINAL_SSH` 절대 경로)를 `sshArgs()` 로: `-t -o ControlMaster=auto -o ControlPath=<userData>/ssh/%C -o ControlPersist=600 -o ServerAliveInterval=15 -o ServerAliveCountMax=3 -- <host> <원격 명령>`. 원격 명령 = `cd '<cwd>' 2>/dev/null || echo …; command -v tmux … && exec tmux new-session -A -s tm-<paneId>; exec "${SHELL:-/bin/sh}" -l`. host · cwd 는 main 이 다시 검사(`isSshHost` — `-` 로 시작 · 공백 · 제어 글자 거절, cwd 는 줄바꿈 · NUL 거절, 작은따옴표는 `'\''`). 앱은 비밀번호 · 키를 갖지 않는다 |
| 호스트당 연결 하나 | ControlMaster · ControlPath(`<userData>/ssh`, 0700) — 분할 · 탭이 같은 연결 |
| 호스트 키 확인 | ssh 자신의 known_hosts 확인을 쓴다(앱이 파일을 쓰지 않음). 출력에서 '처음 보는 서버' 질문을 알아보면 일감 머리 띠 '처음 보는 서버예요 · 지문 SHA256:…' [맞아요, 연결 ↩](= pane 에 `yes`) [취소](= `no`). 'HOST IDENTIFICATION HAS CHANGED' 면 빨간 띠 '서버 키가 바뀌었어요 · 연결하지 않았어요' + `ssh-keygen -R <host>` 복사, 다시 붙지 않는다 |
| 끊김 · 다시 붙기 | ssh 가 255 로 끝나면(키 바뀜 · 인증 거절이 아니면) 1 · 2 · 4 · 8 · 8초 뒤 다섯 번 같은 pane id 로 다시 spawn. 띠 '‹host› 와 연결이 끊겼어요 · n초 뒤 다시 붙어요 (k/5)' [지금 다시 ⌘R]. 다 실패하면 '다시 붙지 못했어요' + 일감을 '확인 필요' 로. 인증 거절(Permission denied)은 띠 '연결하지 못했어요 · 키 인증이 거절됐어요' [다시 시도 ⌘R] |
| 다시 붙는 동안 키 | 끊긴 동안 친 키는 버린다(24단계 early 큐는 첫 spawn 만) — 띠가 알린다 |
| 재시작 뒤 | 지킴이가 ssh 프로세스를 살려 두므로 앱만 껐다 켜면 그대로 붙는다. 셸까지 끝냈다 켜면 새 ssh → tmux 가 있으면 같은 `tm-<paneId>` 세션에 다시 붙음 |
| 새 일감 대화상자 | '이 Mac ⌥1 / 원격 (SSH) ⌥2' · 호스트 칸(↑↓ 로 `~/.ssh/config` 의 Host 목록 — main 이 읽기만, 와일드카드 제외) · 작업 폴더(원격 경로) · '끊겨도 계속 돌게 (서버의 tmux 사용)' 기본 켬 |
| 표시 | 사이드바 일감 줄 · 일감 머리 '⇄ host' 칩 + 연결 점. 원격 일감은 포트 감지 · cwd 탐지 대상에서 뺀다(로컬 pid 가 아님) |

## 3. 순서 · 겹침 · 끝 경로

- 이중 입력: ⌥⌘A 를 두 번 눌러도 이미 보관이면 아무것도 안 함. '끄고 보관' 을 실행 중 다시 누르기 = 확인 창이 닫혀 한 번. 되살리기 두 번 = archivedAt 이 없으면 무시. 다시 붙기 '지금 다시' 를 대기 중에 누르면 대기 타이머를 지우고 한 번만(한 번에 하나 — 진행 중 spawn 이 있으면 무시).
- 취소 · 닫기: 확인 창 취소면 그대로. 보관함 · 주간 정리는 Esc 로 닫힘. 다시 붙기 대기 중 pane 을 닫으면 타이머를 지운다(닫힌 pane 에 spawn 하지 않음). 띠의 [취소](처음 보는 서버) = `no` → ssh 가 끝나고 다시 붙지 않는다.
- 결과를 모를 때: 보관 = 상태 저장(원자적) · 셸 끄기 요청 — 저장 실패는 지금 저장 실패 줄이 알린다. 다시 붙기의 spawn 이 오류로 끝나면 다음 시도로 넘어간다.
- 다시 시도: 다섯 번 실패 뒤 ⌘R / [지금 다시] 가 처음부터 다섯 번.
- 고른 뒤 나중에 실행(r4ee705): 확인 창이 열린 사이 일감이 지워지거나 이미 보관되면 id 로 다시 찾아 없으면 아무것도 안 함. '보관할까요? n' 은 누른 순간의 목록을 id 로 다시 찾는다. 보관함 되살리기는 id 로 다시 찾는다.
- 옛 응답(⑦): '최근 지운 것' · 주간 정리 · 호스트 목록 읽기는 열 때마다 요청 번호를 올리고 늦게 온 옛 응답은 버린다. 주를 빠르게 바꿀 때도 같다.
- 부수 요청(⑧): 다시 붙기 타이머는 pane 마다 한 번에 하나, 창이 안 보일 때도 돈다(셸 연결이라 — 띠가 알림). 주간 정리는 열 때 한 번 읽고 주 바꾸기는 같은 데이터에서 계산(다시 읽지 않음) — 건너뛴 다시 받기 없음.
- 처음 한 번 읽는 값(⑨): 호스트 목록은 대화상자를 열 때마다 다시 읽는다. 주간 정리는 연 순간의 기록 — 열린 동안 끝난 명령은 다시 열면 보인다(낡을 수 있음을 알고 둔다).
- 끝 경로 4개(앱 종료 · 창 닫기 · 새로 고침 · 렌더러 충돌): 보관은 상태 파일의 `archivedAt` 하나라 어느 경로든 저장된 그대로. 보관 중 셸 끄기 요청이 가기 전에 앱이 끝나면 다시 켤 때 보관 일감의 pane 은 그리지 않으므로 지킴이에 남은 셸은 '주인 없는 셸' 목록(16단계)에 나온다 — 앱 시작 때 보관 일감 pane 의 남은 셸을 한 번 끈다. 원격 pane 은 지킴이가 ssh 를 들고 있어 앱 종료 · 새로 고침 뒤 다시 붙고, 다시 붙기 대기 중에 앱이 끝나면 다시 그릴 때 그 pane 은 '끝난 셸' 이라 처음 spawn 으로 새로 연결한다(끝 표시를 쓰지 않으므로 열린 채 남는 기록 없음).

## 4. 시험

- `remote.ts`: `isSshHost` · `sshArgs`(옵션 · `--` · 원격 명령의 따옴표 · tmux 켬/끔) · `parseSshConfigHosts`(와일드카드 · 여러 이름 · 주석) · `sshOutputSignal`(처음 보는 서버 + 지문 · 키 바뀜 · 인증 거절) · `reconnectDelay`.
- 모델: normalizeState 가 archivedAt · host · remoteTmux 를 읽고 이상한 값은 버림.

이번 축소(→ 결과 절 '계획과 다르게 한 것'): 주간 정리 AI 토큰 칸 · 보관할 때 'worktree 폴더 · 브랜치도 지우기' · 최근 지운 것의 '바로 지우기'(백업에서 하나만 지울 수 없음) · 원격 세션 목록(⋯) · pane 을 닫을 때 서버 tmux 세션 끝낼지 묻기(기본 = 남기기 그대로) · 전체 보기 카드 칩(전체 보기 화면 없음).

## 7. 결과 — 계획과 다르게 한 것 (구현 중 적음)

- 25a: '최근 지운 것' 은 이유가 '지움' 인 백업만이 아니라 30일 안의 모든 백업에서 찾는다 — 지우기 직전 모습이 시작 · 자동 백업과 같으면 '지움' 백업이 따로 생기지 않는다(같은 내용 건너뜀, e2e 에서 확인). 계획 값: 'delete' 이유만.
- 25a: 주간 정리의 AI 토큰 칸은 뺐다(스파이크 0절 — 일감별 원천 없음). '마지막 상태' 칸은 보관 여부만.
- 25b: ssh 알림에 `refused`(Host key verification failed)를 더했다 — 지문 질문에 '취소'(no) 한 뒤 다시 붙으면 같은 질문이 끝없이 돈다(e2e 가 찾음). 알아보는 순서도 '끝난 결과(키 바뀜 · 거절 · 인증) → 질문' 으로 바꿨다 — 한 시도의 출력에 질문이 남아 있어 뒤의 거절을 못 봤다.
- 25b: 호스트 칸의 ↑↓ 목록은 자체 목록 대신 `<datalist>`(Chromium 의 ↑↓ 제안). 시험은 option 값만 본다 — 제안 창을 ↑↓ 로 고르는 것은 미확인.
- 25b: 원격 일감은 템플릿을 쓰지 않는다(셸 하나) — 템플릿의 대화 · 검토 칸은 이 Mac 에서 도는 것이라 원격 폴더와 맞지 않는다. 대화상자에서 원격이면 템플릿 칸을 숨긴다. 이미 있는 원격 일감에서 ⇧⌘J(대화) · 변경 검토를 여는 것은 막지 않았다 — 원격 폴더 경로로 이 Mac 에서 돈다(알려진 한계, development.md '1차 출시까지 남은 것').
- 25b: 다시 붙기 기다림은 시험을 위해 한 걸음 단위를 `TASKMINAL_SSH_RETRY_MS` 로 줄일 수 있게 했다(기본 1초). 15초 넘게 붙어 있다 끊기면 다섯 번을 처음부터 센다(`STABLE_MS`).
- 25b: ssh 알림은 연결 시도마다 앞 16KB 출력에서만 찾는다(`SIGNAL_SCAN_MAX`) — 원격 셸 안의 'Permission denied (' 같은 글을 연결 실패로 읽지 않게.
