### 백업 — 언제 만드나 (보드 '이렇게 만듭니다')
백업 = 그 순간 디스크의 `state.json` 사본(바뀌기 **전** 모습). main 의 상태 쓰기(Debouncer 의 write) 안에서, 새 상태를 쓰기 직전에 판단한다 — renderer 를 믿지 않고 main 이 직전 상태와 비교한다.
| 이유(칩) | 언제 | 비고 |
|---|---|---|
| 시작 | 앱이 상태를 읽은 직후(정상 · 고친 것) | |
| 버전 | 시작 때 `backups/last-version` 과 앱 버전이 다르면 '시작' 대신 | 90일 보존 |
| 지움 | 새 상태에서 일감 · 탭이 하나라도 사라지면 | |
| 설정 | 설정(템플릿 · 상태 · 묶음 포함)이 바뀌면 — 10분에 한 번까지(연달아 바꾸면 처음 모습이 남게) | |
| 자동 | 한 시간마다 바뀐 게 있으면 | '하루의 마지막' 은 이것 + 보존 규칙(하루 하나는 그날 마지막)으로 |
| 되돌리기 전 · 가져오기 전 | renderer 가 되돌리기 · 가져오기 직전에 요청(main 이 디바운스를 먼저 비우고 복사) | |
| 복구 | 깨진 파일로 시작해 백업에서 되살렸을 때, 깨진 원본은 `state.json.<시각>.bak`(지금처럼) | |
같은 내용(sha256)이 바로 앞 백업과 같으면 만들지 않는다. 백업 쓰기 실패는 상태 저장을 막지 않는다 → 노란 줄 '백업을 만들지 못했어요 (이유) — 상태는 계속 저장돼요'.

보존(`prune`, 백업을 만들 때마다): 24시간 안 = 모두 · 30일 안 = 하루(이 Mac 시간대) 하나(그날 마지막) · '버전' = 90일 · 그 밖은 지움. 가장 새 것 하나는 언제나 남긴다.

### 되돌리기
- 설정 › 백업(⌘P '백업에서 되돌리기…'): 목록을 오늘 · 어제 · 이번 주 · 그 전(접힘)으로 묶고 줄마다 시각 · 이유 칩 · 일감 수. ↑↓ 로 고르면 오른쪽에 미리 보기(지금과 비교): 다시 생길 일감 · 사라질 일감 · 바뀐 일감(탭 수) · 바뀐 설정 칸 · 템플릿 차이.
- 미리 보기의 일감 줄마다 [이 일감만 되살리기](기본 — 지운 일감 · 바뀐 일감) · 아래에 [전체 되돌리기…](빨강, 두 번째).
- 전체 되돌리기 확인: '이 시점으로 모두 되돌릴까요? 지금 모습은 '되돌리기 전' 백업으로 남아요. 터미널 n개가 끝나요.' [취소 Esc][되돌리기 ⌘⌫]. ↩ 는 위험 동작이 아니도록 '취소' 에 둔다(보드: ↩ = 이 일감만 · ⌘⌫ = 모두).
- 순서: renderer → `backup.mark('restore')`(main 이 디바운스 비움 → 지금 state.json 을 '되돌리기 전' 으로 복사) → 성공하면 renderer 가 상태를 바꾸고 → 평소 저장(원자적 rename 한 번). mark 가 실패하면 되돌리지 않고 '지금 모습을 백업하지 못해 되돌리지 않았어요' — 결과를 모를 일이 없다(main 은 같은 프로세스, invoke 실패 = 안 함).
- 이중 입력: 되돌리는 중(mark 를 기다리는 동안) 버튼을 막는다. 두 번 눌러도 한 번만.
- 닫기 · 취소: 확인 창 Esc · 설정 닫기 = 아무것도 안 바뀜. mark 가 끝난 뒤 설정을 닫아도 되돌리기는 끝까지 간다(백업 하나가 더 남을 뿐).
- 일감 하나 되살리기(`restoreTask`): 그 일감이 지금 있으면 그 자리에서 바꾸고, 없으면 원래 순서 자리에 넣는다. 지금 없는 상태(statusId) · 묶음(groupId)은 백업의 설정에서 가져와 더한다(스파이크 4 — 사라진 참조). 다른 일감과 겹치는 탭 · pane id 는 새 id 로.
- 전체 되돌리기(`restoreAll`): 백업의 상태 그대로(설정 포함). 지금 상태의 pane 중 백업에 없는 것은 셸을 끝낸다(kill).

### 셸 지킴이(16단계)와 겹침
pane id 는 UUID — 같은 id 는 같은 pane 이다. 되살린 상태의 pane 은 TerminalPane 이 마운트되며 `pty.attach` 를 먼저 한다:
- 지금도 살아 있는 pane(되돌리기 전후 모두 있음): 같은 셸에 그대로 붙어 있다 — 새로 띄우지 않고 출력이 이어진다(시험: 전체 되돌리기 뒤 그 pane 의 pid 가 같다).
- 백업에만 있는 pane(지운 일감): 지울 때 셸을 끝냈으므로 지킴이에 없다 → 13단계처럼 폴더에서 새 셸(남은 스크롤 파일이 있으면 되살림). 지킴이에 주인 없는 셸로 남아 있던 id(손상 복구 뒤 등)면 그 셸에 다시 붙는다 — 사용자가 잃었던 셸을 되찾는 쪽이라 그대로 둔다.
- 되살리기 결과에서 사라지는 pane(지금만 있음): renderer 가 kill — 확인 창에 '터미널 n개가 끝나요'.
- 다른 일감과 id 가 겹치는 일(가져오기 · 같은 백업을 두 번)은 `restoreTask` · `mergeState` 가 새 id 를 줘서 pty 하나를 두 화면이 나누지 않게(normalizeState 의 규칙과 같음).

### '지우기' 의 되돌리기 알림 (25단계 '최근 지운 것' 전까지)
일감을 지우면 아래 알림 '‘이름’ 일감을 지웠어요 [되돌리기 ⌘Z]' 8초. 되돌리기 = 지울 때 renderer 가 들고 있던 일감을 `restoreTask` 로 원래 자리에(셸은 이미 끝났으니 새로 뜸 — 알림 뒤 글 '셸은 새로 열려요'). 8초가 지나면 '설정 › 백업' 의 '지움' 백업으로만 되살린다. 25단계가 '최근 지운 것 30일' 로 바꾼다.
⌘Z 는 알림이 떠 있을 때만 앱이 받는다(글 칸에서는 받지 않음). 탭 닫기는 알림 없음(백업만).

### 손상 자동 복구
`StateFile.load` 가 `corrupt` 면: 원본을 `.bak` 으로 옮기고(지금처럼) → `BackupStore.latestGood()`(새 것부터 `readStateText` 가 ok 인 첫 것) → 있으면 그 상태로 시작 · notice `recovered` + 백업 시각 '저장 파일이 손상돼 11-11 09:02 백업으로 되살렸어요. 손상된 파일은 옆에 남겨 뒀어요.' · 없으면 지금처럼 빈 상태 + `corrupt`.
되살린 상태는 바로 저장(다음 실행이 또 복구하지 않게).

### 내보내기 · 가져오기
- 내보내기(설정 › 백업): 저장 창 → 상태 JSON 을 `exportText`(= `redact` 를 거친 글 — 명령 · 이름 속 키도 가림, 출력 · 스크롤은 넣지 않음)로 0600 저장.
- 가져오기: 열기 창 → 5MB 상한 · `readStateText` 가 ok 인 것만 → 미리 보기(diff) → [합치기(추천) ↩] [바꾸기…] [취소 Esc]. 합치기 = 없는 일감 · 템플릿 · 상태 · 묶음을 더함(겹치는 id 는 새 id). 바꾸기 = 전체 되돌리기와 같은 확인. 둘 다 '가져오기 전' 백업 뒤에.
- 열기 · 저장 창은 main 의 dialog — e2e 는 `app.evaluate` 로 dialog 를 바꿔 끼워 시험.

### 비밀값 — 화면
- 설정 '화면에서 비밀값 가리기'(기본 켜짐) · 종류별 화면 표시(강한 종류 켜짐, '이름 붙은 값' 꺼짐).
- 가린 칸 decoration: 중립 회색 배경 · 점선 테두리 · 첫 칸에 '🔒 종류 · 보기'. 클릭 → 메뉴 [이 칸 보기 ↩ · 원문 복사 ⌘C · 비밀값 아님 — 다시 가리지 않기]. '보기' 는 그 칸만 열고(실선) 다시 누르면 가림.
- 칩: pane 오른쪽 위 '🔒 N개 가림' → 목록(같은 값은 ×N 으로 묶음) + [모두 30초 보기].
- pane 마다 처음 가렸을 때 한 번 안내 '이 출력에서 비밀값 N개를 가렸어요. 화면을 공유 중이었다면 키를 바꾸는 게 안전해요.' [어떤 것들인지 보기][괜찮아요].
- 복사: 선택 안에 가린 값이 있으면 ⌘C(복사 이벤트 · 선택하면 바로 복사 둘 다)가 ‹가림:종류› 로 바꿔 복사(Warp 와 같음). 원문은 칸 메뉴 [원문 복사] 로만.
- '비밀값 아님': 그 값의 해시를 설정 `secretAllow` 에 {해시, 종류, 일감 이름, 시각} → 화면 · 디스크 모두 다시 가리지 않음 → 알림 '이 값을 이제 가리지 않아요. 디스크에도 원문으로 남아요. [되돌리기 ⌘Z]'. 설정 › 개인정보 '가리지 않기로 한 값' 목록 [다시 가리기].

## 계획과 다르게 한 것
- **사용자가 부른 백업은 같은 내용이어도 만든다**(`snapshot(…, force)`): 계획은 '같은 내용이면 만들지 않는다' 하나였으나, '되돌리기 전 · 가져오기 전' 이 바로 앞 백업과 같으면 안 생겨 알림이 가리키는 백업이 목록에 없었다(e2e 에서 발견). 자동 이유(시작 · 지움 · 설정 · 자동)는 계획대로 건너뛴다 — 그래서 시작 직후 지우면 '지움' 대신 같은 내용의 '시작' 백업만 남을 수 있다(되살리는 데는 같음).
- **TerminalPane 이 모달(aria-modal) 이 열린 동안 포커스를 가져가지 않는다**: 계획에 없던 변경. 되돌리기 뒤 다시 마운트된 터미널이 설정 창의 포커스를 빼앗아 ↑↓ 가 셸로 갔다(e2e 에서 발견).
- **백업 목록 ⌘F 거르기(보드)는 만들지 않았다**: 보존 규칙상 목록이 수십 개 안팎이라 묶음 + ↑↓ 로 충분하다고 봄. 필요하면 25단계 보관함과 함께.
- **내 종류 더할 때 '지금 화면에서 N곳이 걸려요' 미리 보기(보드)는 만들지 않았다**: 모양 오류 안내만. 더한 뒤 화면이 바로 다시 훑어 결과가 보인다.
- **'하루의 마지막' 백업**은 따로 시각을 두지 않고 계획 표대로 '자동(한 시간마다 바뀐 게 있으면)' + 보존 규칙으로만 한다.
- 시험: 계획 목록 모두 있음. 빠진 것 없음.
