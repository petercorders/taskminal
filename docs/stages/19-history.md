## 늦게 오는 응답 · 부수 요청 · 처음 한 번 읽는 값 (r5cce92)

- 옛 응답: 모든 출력 찾기는 조각마다 세대 번호를 보고 다르면 버린다. 저장된 스크롤 읽기(invoke)도 세대가 바뀌었으면 결과를 버린다. 기록 목록 읽기(`history:list`)는 앱이 처음 읽힐 때 한 번 — 그 사이 D 로 생긴 줄은 메모리에 더해 두고, 읽은 목록과 id 로 합친다(겹치지 않게).
- 부수 요청: 찾기는 한 번에 하나(새로 시작하면 앞 것을 버림). 기록 쓰기는 D 마다 하나 — 실패한 것은 대기열에 두고 다음 쓰기 · [다시 저장] 때 함께 보낸다(쌓여도 한 번에 하나만 보냄 · 상한 500줄).
- 처음 한 번 읽는 값: 기록 목록은 처음 한 번만 읽고 그 뒤는 메모리가 기준(이 앱 말고 쓰는 곳이 없음). 가리기 옵션은 main 이 쓸 때마다 새로 읽는다(17단계 ScrollbackStore 와 같음). 찾기의 일감 · pane 목록은 찾기를 시작할 때 떠 둔다 — 그 사이 닫힌 pane 은 ↩ 때 다시 찾는다.

## 결과를 모를 때 · 다시 시도 · 이중 입력 · 취소 (plan-check ①~④)

- 결과를 모를 때: 기록 저장(invoke)이 실패하거나 응답 유실이면 저장 실패 줄을 띄우고 그 줄을 대기열에 둔다 — 화면의 기록은 그대로.
- 다시 시도: [다시 저장] · 다음 기록 때 대기열을 앞에서부터 다시 보낸다. 같은 id 가 두 번 가면 main 이 id 로 거른다(덧붙이기 전에 그 파일의 id 를 본다 — 이중 저장 방지).
- 이중 입력: 지우기는 같은 id 를 두 번 눌러도 한 번(이미 지운 표시면 무시), 실행 중 다시 누르기 = ⌥↩ 를 빨리 두 번 → 분할 두 개(사용자가 원한 것으로 본다 — 키 반복은 막음).
- 취소 · 닫기: 기록 칸 · 찾기 창을 닫으면 하던 찾기를 버린다. 지우기 토스트를 닫으면(5초) 그때 파일에서 지운다.
