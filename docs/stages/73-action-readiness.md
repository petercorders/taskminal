# 73단계 — 받을 알림과 시작할 일을 확인하기

## 전체 보기에서 지금 할 일 열기

**지금 할 일**은 기존 **지난 알림** 위에 표시된다.

- 입력 대기 중인 셸과 현재 열려 있는 대화 질문·허락은 해당 화면을 연다. 같은 대화에 질문이 여럿이면 마지막 대답이 해결될 때까지 행을 남긴다.
- 확인하지 않은 셸 실패와 현재 대화의 실패는 조사할 화면을 연다. 해당 행을 열거나 새 실행이 시작되면 현재 실패 행을 내린다.
- 로컬 Git 일감에서 성공한 대화 결과는 **결과 검토**로 기존 변경 화면을 연다. 변경 화면을 열거나 새 턴을 시작하면 이 제안을 내린다. 일감의 설정 상태가 **리뷰**로 지정된 경우에는 그 상태를 벗어날 때까지 결과 검토를 표시한다.
- 보관한 일감과 닫힌 화면은 현재 목록에서 빠진다. 행을 클릭하면 현재 상태와 대상 탭을 다시 대조한다.

현재 대화 신호는 이 창에서 받은 실시간 이벤트로 판단한다. 앱 재시작 이후에는 지난 알림 기록을 계속 볼 수 있다. GitHub 리뷰와 CI 상태는 별도 PR 패널에서 확인한다.

## 작업 흐름 실행 전 한도 확인

저장된 작업 흐름을 고르고 **계정 한도 확인**을 누른다. 각 단계의 에이전트와 새 대화에 선택된 계정, 조회된 사용률, 초기화 시각을 같은 화면에 표시한다. 같은 계정을 쓰는 단계의 한도는 한 번 조회한다. 계정을 찾지 못하거나 공급자가 값을 내주지 않으면 해당 단계에 미확인으로 표시한다. 이미 초기화된 값은 이전 사용률 대신 초기화됐다고 표시한다.

조회는 실행 전 참고용이다. 조회한 계정이 모두 확인된 경우에는 새 실행의 계정을 고정하기 직전에 현재 선택과 대조한다. 그 사이 계정이나 흐름에 필요한 공급자가 바뀌면 실행을 시작하지 않고 다시 확인할 수 있다. 예약 및 CLI 실행은 기존 계정 선택을 따른다.

## 검증

- 현재 항목의 대상·해결 상태, 복수 질문, 계정 지목·만료·조회 실패 및 실행 직전 대조를 단위 테스트로 확인했다.
- 타입 검사, 아키텍처 경계 검사, Vitest 141파일 1,738개를 통과했다. 응답 하나만 닫기, 검토 대상 Git 확인, 만료된 한도 구별, 실행 전 계정 확인의 변이 4개를 검출했다. E2E는 생략했으며 하네스 종료 코드는 4였다.
- UI/UX는 키보드로 접근 가능한 기본 버튼·목록, 상태 안내, 긴 이름 줄바꿈, 시작 전 실행 위치를 코드에서 확인했다. 실제 GUI 조작, 보조기술과 실계정 확인은 실시하지 않았다.
