# 환경 준비와 선언형 확장

50단계 기능 브랜치의 **환경·확장**에서 현재 로컬 일감 폴더를 기준으로 사용한다. 공개 0.1.2에는 포함되지 않았다.

## Worktree 환경 준비

저장소에 `.taskminal/environment.json`을 직접 작성한다. 설정이 있다는 이유로 자동 실행하지 않는다.

```json
{
  "copies": [".env.local"],
  "commands": [{"file": "npm", "args": ["ci"]}]
}
```

같은 저장소의 별도 worktree 절대 경로를 입력하고 미리보기를 확인한다. 복사할 파일명·크기·기존 파일 보존 여부와 명령 인자가 표시된다. 파일 내용은 표시하지 않는다. 복사 원본은 Git에서 무시하는 일반 파일이어야 하며 대상에서 추적하는 파일은 거절한다. 심볼릭 링크·상위 경로·`.git` 경로도 거절한다. 대상에 이미 있는 파일은 덮어쓰지 않는다. 복사본은 독립 파일이며 `node_modules`를 공유하지 않는다.

**확인하고 환경 준비**를 눌러야 복사·명령 실행을 시작한다. 승인한 설정과 복사 원문은 서명으로 확인하고 한 스냅샷에서 실행한다. 명령은 대상 worktree에서 순서대로 실행되며 각 명령 제한은 120초다. 명령 로그는 비밀값을 가린 뒤 명령 종료 시 표시한다. 설정과 명령을 신뢰하는 로컬 저장소에서 사용해야 하며 OS sandbox를 제공하지 않는다. 다른 프로세스가 동시에 디렉터리 경계를 바꾸는 적대적 상황을 원자적으로 봉쇄하지 않는다.

패널을 닫아도 준비는 계속된다. 다시 열면 실행 기록을 확인하거나 **환경 준비 중단**을 누를 수 있다. 중단은 이 준비가 시작한 프로세스 그룹을 종료하며 이미 복사한 파일·명령의 결과는 남는다. 실패 뒤 새 실행은 설정과 남은 결과를 확인하고 다시 미리보기해야 한다. 완료 응답이 유실되면 같은 요청 번호로 결과를 확인한다. 앱이 실행 도중 종료된 기록은 `unknown`으로 복원하며 명령을 자동 재실행하지 않는다.

## 선언형 로컬 확장

일감 폴더 안에 JSON manifest를 작성한다.

```json
{
  "id": "project-help",
  "name": "프로젝트 도움말",
  "version": "1.0.0",
  "panels": [{"id": "notes", "title": "시작하기", "body": "npm ci 후 npm run dev"}],
  "commands": [{"id": "docs", "title": "공식 문서", "url": "https://example.com/docs"}]
}
```

상대 경로를 입력해 **확장 검사** 후 표시된 패널·링크를 확인하고 설치한다. 본문은 일반 텍스트이며 HTML·JavaScript·Node 코드를 실행하지 않는다. 명령 기여점은 자격 증명이 없는 HTTPS 외부 링크다. 버전을 바꾸면 manifest를 다시 검사·승인한다. 설치 내용은 로컬에 복사해 보관하며 원본 수정만으로 자동 갱신하지 않는다. 활성·비활성·제거는 일감 폴더별로 적용된다. 공개 marketplace와 임의 코드 SDK는 포함되지 않는다.
