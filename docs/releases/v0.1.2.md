# Taskminal 0.1.2

**한 일감 안에서 터미널, AI 대화, 파일과 변경 검토를 이어 가세요.**

이번 버전은 운영체제별 설치 파일과 다운로드 화면을 준비하고, 일감을 오가며 작업을 이어 가는 흐름을 다듬었습니다.

홈페이지는 운영체제에 맞는 파일을 추천하며, 모든 설치 파일을 직접 고를 수도 있습니다. 브라우저가 Mac의 칩을 알려 주지 않으면 Apple Silicon과 Intel을 구분해 선택할 수 있습니다.

## 작업을 한곳에

- **일감별 작업 공간** — 폴더마다 터미널 탭·분할·AI 대화를 묶고, 다른 일감으로 갔다 와도 하던 자리를 유지합니다.
- **Claude와 Codex 대화** — 설치한 CLI와 본인 계정으로 대화하고, 요청·승인·진행 상태를 같은 화면에서 확인합니다.
- **대화 찾기와 이어 가기** — 저장된 대화를 검색하고, 작업 메모와 최근 상태를 보고 다음 작업을 이어 갑니다.
- **파일과 변경 검토** — 파일 탐색·미리보기·대화 맥락 첨부, Git 변경 검토와 GitHub 작업을 앱 안에서 이어 갑니다.
- **브라우저와 작업 도구** — 일감별 브라우저 탭, 에이전트 작업 흐름, 예약과 결과함을 이용할 수 있습니다.

## 더 편하게

- 좁은 창의 사이드바·작업 도구·설정 배치를 다듬었습니다.
- 입력 중인 초안과 포커스를 보존하고, 늦게 도착한 응답으로 화면이 엉키는 경우를 줄였습니다.
- Windows와 Linux에서는 주요 앱 단축키에 `Ctrl`, Mac에서는 `⌘`를 사용합니다.
- 앱 창을 닫아도 셸 지킴이가 작업을 유지합니다. 셸까지 종료하려면 앱 메뉴의 **셸까지 모두 끝내기**를 선택하세요.

## 시작하는 순서

1. 컴퓨터의 운영체제·칩에 맞는 설치 파일을 내려받습니다.
2. 앱에서 폴더를 골라 새 일감을 만듭니다.
3. 터미널을 열거나, 설치·로그인한 Claude Code 또는 Codex CLI로 대화를 시작합니다.

Taskminal 자체 계정은 필요하지 않습니다. AI 서비스의 설치·로그인과 이용 요금은 해당 서비스의 조건을 따릅니다. 자세한 설치와 복구 안내는 [Docs](https://taskminal.petercoders.com/docs/)에서 확인하세요.

## OS별 안내

- **Mac:** Apple Silicon·Intel 모두 macOS 13 이상이 필요합니다. 배포되는 Mac 앱의 서명·공증 상태는 설치 파일과 함께 검증합니다. 운영체제와 칩이 맞는 파일을 선택하세요.
- **Windows:** 첫 베타 빌드는 코드 서명 인증서가 없어 Windows 보안 확인이 표시될 수 있습니다. 포트 자동 감지와 추가 계정의 TUI 전환은 아직 제공하지 않습니다. 실행 중 폴더를 엄격히 확인할 수 없는 worktree 정리는 안전하게 거절합니다.
- **Linux:** 배포판에 따라 시스템 라이브러리가 추가로 필요할 수 있습니다. AppImage는 실행 권한을 부여한 뒤 열어 주세요. `.deb`는 Debian/Ubuntu 계열용입니다. 한글이 네모로 보이는 최소 설치 환경은 CJK 시스템 폰트가 필요합니다([설치 안내](https://taskminal.petercoders.com/docs/#install)).

설치 파일의 SHA-256은 릴리스에 첨부된 `SHA256SUMS`에서 확인할 수 있습니다. 문제가 있으면 [GitHub Issues](https://github.com/petercorders/taskminal/issues)에 운영체제·칩·앱 버전과 재현 순서를 남겨 주세요. 비밀값과 계정 토큰은 포함하지 마세요.
