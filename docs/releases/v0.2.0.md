# Taskminal 0.2.0

> **초안 — 아직 게시하지 않았습니다.** 아래 다운로드 주소는 릴리스를 게시한 뒤에 열립니다. 준비 상태와 남은 승인은 `docs/releases/v0.2.0-prep.md`.

**에이전트가 일하는 동안 무엇이 진행 중인지 보고, 검토하고, 이어 가는 일을 한 앱에서.**

0.1.2 이후 코드를 직접 고치고 검토하는 도구, 여러 에이전트를 함께 돌리는 흐름, 이슈 · CI 연결, 원격 작업 공간이 더해졌고, 터미널에서 돌리는 Claude · Codex 의 상태와 사용 한도를 앱이 직접 보여 줍니다.

## 새로 생긴 것

- **코드 고치기와 줄별 의견** — 파일 탐색에서 바로 고치고 저장합니다. 디스크에서 바뀐 파일은 덮어쓰지 않고 알려 줍니다. 변경 검토의 줄마다 의견을 달아 한 번에 대화로 보냅니다.
- **에이전트 여러 명과 작업 흐름** — 단계를 나눠 여러 대화를 동시에 돌리고, 필요하면 단계마다 따로 워크트리를 씁니다. 실행 중인 단계의 상태 · 질문 · 다시 시도를 한 화면에서 봅니다.
- **이슈와 PR** — GitHub · Linear 이슈에서 일감과 워크트리를 만들고, Jira 이슈를 읽어 일감에 연결합니다(Jira 는 읽기 전용). PR 의 실패한 체크 로그와 리뷰 의견을 보고 그 일감의 대화로 보냅니다.
- **터미널의 Claude · Codex 상태** — 터미널에서 직접 띄운 에이전트도 '작업 중 · 입력 기다림 · 끝남' 이 사이드바와 알림에 반영됩니다. 사용자의 Claude · Codex 설정 파일은 바꾸지 않습니다.
- **사용 한도** — Claude 의 5시간 · 주간 한도와 풀리는 시각을 사이드바와 계정 화면에서 봅니다.
- **밖에서 시작한 세션 이어 하기** — 다른 터미널 · 다른 도구에서 시작한 Claude · Codex 세션을 찾아 대화나 터미널로 이어 갑니다.
- **원격 작업 공간** — 다른 컴퓨터에서 Taskminal 서버를 띄워 파일 · Git · 터미널 · 대화를 그쪽에서 돌리고, 연결이 끊겨도 작업은 이어집니다.
- **워크트리와 환경 준비** — 워크트리 목록에서 '환경 준비' 로 바로 넘어가 설정 파일 복사와 설치 명령을 확인 뒤 실행합니다.
- **브라우저 명령줄 도구** — `taskminal browser …` 로 에이전트가 일감의 브라우저 탭을 읽고 누르고 채웁니다.

## 더 편하게

- 터미널에 파일을 끌어 놓으면 경로가 입력줄에 들어갑니다(실행하지 않습니다).
- 탭을 끌어 순서를 바꿉니다. ⌘P 의 '탭을 왼쪽으로 · 오른쪽으로' 로도 됩니다.
- tmux · vim 같은 터미널 안 프로그램의 복사가 Mac 클립보드로 옵니다(설정 › 터미널에서 끌 수 있습니다).
- 대화의 Claude 가 `taskminal` 명령(메모 남기기 · 다른 대화에 맡기기 · 브라우저)을 압니다(설정 › 일반 › 대화에서 끌 수 있습니다).
- Claude · Codex 이름 옆에 각 도구의 로고를 보입니다.
- ⌘P · 찾기 화면이 옆 패널 위에 뜨고, Esc 로 옆 패널을 닫습니다. 위 도구 줄을 '이 일감' 과 '앱' 두 묶음으로 정리하고 찾기 네 곳을 '찾기 ▾' 하나로 모았습니다.
- 원격 터미널에 오래 입력하면 서버가 더 받지 않던 문제를 고치고, 먼 서버에서 입력이 밀리지 않게 묶어 보냅니다.

## 알아 둘 것

- Jira 는 읽기만 합니다. 상태 바꾸기 · 댓글은 아직 앱에서 하지 않습니다.
- 원격 작업 공간 · Windows · Linux 는 베타입니다.
- Taskminal 자체 계정은 필요하지 않습니다. AI 서비스의 설치 · 로그인과 이용 요금은 해당 서비스의 조건을 따릅니다.
- Claude · Codex 로고는 각 회사(Anthropic · OpenAI)의 상표입니다. 고지는 앱에 함께 들어 있는 `THIRD_PARTY_NOTICES.md` 에 있습니다.
