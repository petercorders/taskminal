# 0.2.0 출시 준비 — 상태와 남은 승인

2026-11-18 사용자 "이거 끝나면 업데이트 한번하게 준비해줘". **준비까지만 했다 — 태그 · GitHub 릴리스 게시 · 공증 제출 · 사이트 배포 · `/Applications` 설치는 하지 않았다**(`docs/development.md` 의 승인 규칙: 공개 릴리스는 별도 명시적 요청).
브랜치 `release/0.2.0-prep`(base `origin/main` 2d6f4fc = 59단계까지). 지금 공개 버전은 0.1.2(태그 `v0.1.2`, 43단계)이고 그 뒤 44~59단계가 출시되지 않은 채 main 에 있다.

| 릴리스 노트 | 초안 `docs/releases/v0.2.0.md` — 0.1.2 노트와 같은 틀. 다운로드 주소는 게시 뒤에 열린다 |

## 게시 전에 정할 것 (사용자 승인)
1. **e2e 를 한 번 돌릴지 — 추천: 돌린다.** 58 · 59단계는 지시대로 e2e 없이 병합했다. 공개본에 들어가므로 게시 전 전체 e2e 1회(약 10분, 이 Mac 에 앱 창이 뜬다)를 권한다. 먼저 볼 목록: `docs/stages/58-remote-input-guide-gestures.md` · `docs/stages/59-agent-icons.md` 의 '돌려야 할 e2e'. 실패가 나오면 고친 뒤 다시 준비한다.
2. **네 OS CI** — `.github/workflows/multi-platform.yml` 은 main push 로는 돌지 않는다(옛 브랜치 push · 수동 실행만). 마지막 실행은 0.1.2 때(2026-11-13)라 44~59단계는 Windows · Linux 에서 한 번도 빌드 · 실행되지 않았다. 준비 PR 을 연 뒤 이 브랜치로 수동 실행을 걸어 둔다 — 실행 주소와 결과는 준비 PR 본문에 적는다(이 문서를 쓸 때는 결과가 없다). 게시하지 않는 워크플로다.
3. **Mac 서명 · 공증** — `npm run release`(두 칩, dmg + zip + `latest-mac.yml`, Apple 에 공증 제출). 게시는 하지 않는 명령이지만 Apple 에 제출이 나간다.
4. **게시** — 태그 `v0.2.0` · GitHub 릴리스(설치 파일 · blockmap · `latest*.yml` · manifest · `SHA256SUMS` — 0.1.2 는 22개). 게시하는 순간 0.1.2 사용자의 자동 업데이트가 이 버전을 받는다.
5. **사이트 · README** — 다운로드 주소가 0.1.2 를 가리킨다(`site/index.html` · `site/en/index.html` · `site/docs/` · `README.md`). `site/` 를 main 에 push 하면 Pages 가 배포된다 — 게시와 같은 때에.
6. **이 Mac 의 설치본** — `/Applications` 의 Taskminal 을 0.2.0 으로 바꿀지(자동 업데이트로 받을지 · 직접 설치할지).

## 게시 순서 (승인 뒤, 43단계 때의 절차)
1. (정하면) e2e 전체 → 2. 이 준비 PR 을 main 에 병합 → 3. 네 OS CI 통과 · Windows/Linux 산출물 받기 → 4. `npm run release` 로 Mac 두 칩 서명 · 공증 · staple · `check-package --release` → 5. 산출물 해시 · manifest · `SHA256SUMS` → 6. 태그 `v0.2.0` · GitHub 릴리스(노트 = `v0.2.0.md` 에서 '초안' 줄 빼고) → 7. 사이트 · README 링크 → Pages → 8. 공개 주소에서 내려받아 해시 대조 · 0.1.2 앱에서 업데이트 알림 확인.

## 미검증 · 위험
- 58 · 59단계의 실제 화면 동작(끌어 놓기 · OSC 52 · 탭 끌기 · 로고 모양 · 새 설정 행) — e2e · 화면 리뷰 없음. 사용자가 임시 데이터로 띄운 빌드에서 직접 보는 중.
- 대화 claude 에 붙이는 안내 인자(`--append-system-prompt`)가 실제 claude 에서 문제없이 도는지.
- 0.1.2 → 0.2.0 자동 업데이트 경로는 게시해야만 확인된다. 받은 사용자는 되돌릴 수 없으니 게시 직후 한 대에서 먼저 확인한다.
- Windows · Linux 는 44단계 뒤로 실제 환경 확인이 없다.
