## 새로 더할 것 (사용자 요청)

### 1. 일감 전체를 한눈에 관리하는 창 (2026-11-10)
사용자: "orca 작업처럼 한번에 작업을 관리할 수 있는 창이 있어야지". 디자인 캔버스에는 없다 — 화면 디자인부터 해야 한다.

참고 — Orca 'Agent Dashboard'(https://www.onorca.dev/docs/model/agents-sessions, 2026-11-10 확인):
- 칸반 4칸: **Needs You**(권한 · 질문 기다림) · **Working** · **Done**(끝남, 검토 필요할 수 있음) · **Idle**(30분 넘게 조용, 기본 숨김)
- 카드: 세션 이름 · 상태 모양 · **마지막 메시지 미리보기** · 프로젝트 · 워크트리 · 경과 시간. Needs You 는 노랑, Done 은 초록으로 칠함 · 원격(ssh) 표시 · 하위 에이전트는 펼치는 줄
- 위 막대: 이름 찾기 · 프로젝트 / 상태 / PR 상태 거르기
- 카드를 누르면 그 터미널로 감. 사이드바 항목 · 단축키로 열고, 창 안 또는 따로 띄운 창(Pop-out)

Taskminal 로 옮긴 안 (추천, 사용자 확인 전):
- 칸 = 9단계 활동 그대로: **확인 필요**(입력 기다림 · 실패) · **실행 중** · **끝남** · **조용함**(접힘)
- 카드 단위 = **pane**(터미널 하나 — Claude 하나가 pane 하나), 카드 위에 일감 이름 · 색, 본문은 그 pane 의 마지막 출력 1~2줄, 아래에 폴더 · 경과 시간 · 명령
- 거르기: 묶음 · 상태(사용자 상태) · 찾기
- 열기: 사이드바 맨 위 '전체 보기' + 단축키(⇧⌘O 후보) — 본문 자리에 띄움(따로 창은 나중)
- 카드에서: 누르면 그 pane 으로 · 확인 필요 카드는 마지막 질문을 크게

정할 것: 카드 단위(pane / 일감) · 본문 자리 vs 따로 창 · 끝남 카드를 언제 '조용함' 으로 내릴지(Orca 30분)
