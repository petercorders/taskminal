일감별로 묶기

폴더 하나에 탭 · 칸 · 메모 · 명령 기록. 사이드바에서 할 일 → 하는 중 → 리뷰 → 완료로 옮겨요.

껐다 켜도 그대로

셸은 앱 밖에서 계속 돌아요. 다시 열면 같은 셸에 붙고 출력이 이어집니다.

에이전트와 나란히

Claude · Codex 대화 칸과 터미널을 한 화면에. 허락 · 질문은 카드로 답해요.

에이전트와 일하는 하루

맡기고, 검토하고, 이어 가기

여러 에이전트를 명령줄에서 지휘

taskminal 명령으로 일감 · 탭 · 칸을 만들고, 대화를 띄우고, 끝날 때까지 기다려요. Claude 가 터미널 안에서 스스로 일을 나눠 맡길 수도 있습니다.

명령줄 도구는 앱 메뉴 › 명령줄 도구 설치… 로 직접 깔아요. 셸 설정 파일은 건드리지 않습니다.

# 두 에이전트에게 나눠 맡기고
$ taskminal chat new --agent claude "결제 시험 고치기"
$ taskminal chat new --agent codex "환불 문서 정리"
# 둘 다 끝날 때까지 기다린다
$ taskminal chat wait --all
끝남  결제 시험 고치기
끝남  환불 문서 정리

고친 것을 보고, 고른 것만 커밋

에이전트가 고친 파일을 diff 로 보고, 줄을 골라 되돌리고(⌘Z 로 복구), 체크한 파일만 커밋해요.

며칠 만에 열어도 어디까지 했는지

오래 비운 일감을 열면 '어디까지 했나' 카드가 맨 위에 떠요. 확인이 필요한 것부터 보여 줍니다. 대화 칸은 재시작해도 같은 세션을 이어 갑니다.

어디까지 했나 · 결제 API 고치기3일 만에 열었어요
확인 필요시험 칸 · npm test 실패 1개 (refund 금액 0)
마지막 명령git push origin fix/refund
메모환불 한도는 원 결제 금액까지
함께 쓰는 에이전트 Claude Code · 대화 칸 Codex · 대화 칸 그 밖의 CLI 에이전트 · 터미널 칸

한 일감에 필요한 것이 한곳에

자주 쓰는 동작에는 단축키가 붙어 있어요.

일감별 탭 · 분할

일감마다 탭과 분할을 따로 기억해요. 자주 쓰는 구성은 템플릿으로 저장합니다.

앱을 꺼도 셸은 그대로

셸은 앱 밖의 지킴이가 붙잡고 있어요. 모두 끝내려면 ⌥⌘Q

명령 기록 · 모든 출력 찾기

일감마다 언제 무엇을 돌렸는지 ⌘Y, 모든 일감의 출력을 한 번에 ⇧⌘F

빠른 명령 · 포트 칩

자주 쓰는 명령을 단추로 ⌥1~9. 개발 서버가 열면 포트 칩이 뜨고, 눌러서 브라우저로 · 끄기.

보관함 · 이번 주

끝난 일감은 셸만 끄고 보관 ⌥⌘A. 지운 일감은 30일 안에 되살려요.

SSH 원격 일감

호스트:경로로 일감을 열어요. 연결 하나를 칸끼리 나눠 쓰고, 끊기면 tmux 세션에 다시 붙습니다.

내 작업과 비밀값을 지키는 기본기

출력 속 비밀값 가리기

API 키 · 토큰 모양은 디스크에 저장할 때 늘 가리고, 화면에서도 가릴 수 있어요. 기록 · 찾기 · 알림에도 같은 규칙.

자동 백업 · 되돌리기

일감 · 설정을 자동으로 백업하고, 상태 파일이 깨지면 마지막 정상본으로 시작합니다. 내보내기 · 가져오기도.

이 Mac 안에서만

계정 · 서버 없이 동작해요. 셸 소켓은 내 사용자만 열 수 있고, 오류 기록도 이 Mac 에만 남습니다.

자주 묻는 것

무료인가요?+

네. MIT 라이선스 오픈소스이고 계정이나 결제가 없어요.

Intel Mac · Windows · Linux 에서도 되나요?+

지금은 Apple Silicon(M1 이후) Mac 전용이에요. 다른 환경은 아직 빌드하지 않습니다.

어떤 에이전트와 쓸 수 있나요?+

Claude Code 와 Codex 는 대화 칸으로 띄워 허락 · 질문을 카드로 답해요. 그 밖의 명령줄 에이전트는 터미널 칸에서 그대로 돌리면 됩니다.

앱을 끄면 돌던 명령은 어떻게 되나요?+

셸은 앱 밖의 지킴이가 붙잡고 있어서 계속 돌아요. 다시 열면 같은 셸에 붙습니다. 셸까지 모두 끝내려면 ⌥⌘Q.

내 데이터는 어디에 저장되나요?+

일감 · 설정 · 출력 기록은 이 Mac 에만 저장돼요. 계정이 없고, Taskminal 이 따로 보내는 곳은 없어요(업데이트 확인만 GitHub 에 해요). 대화 칸의 Claude Code · Codex 는 각자 원래대로 자기 서버와 통신합니다. 저장할 때 비밀값 모양은 가려요.

업데이트는 어떻게 받나요?+

새 버전은 GitHub Releases 에 올라가고, 앱이 알아서 확인해 받아요.
