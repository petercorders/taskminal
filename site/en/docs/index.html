Your first three minutes

  1. Create a task for your project folder.

    Choose “새 일감” (new task) in the app and select a folder. A task groups a folder, tabs, conversations and shells.

  2. Start with a conversation or a terminal.

    Choose Claude, Codex or a shell. You can use the terminal before installing an AI CLI.

  3. Bring up a shell, then switch tasks.

    Use ⌘J on Mac or Ctrl+J on Windows and Linux. Return to the task to continue in the same workspace.

Looking for a command? Open the command palette with ⌘P / Ctrl+P and search by name. The current app interface uses Korean labels; this guide includes the labels you need.

Initial Windows limitations

The terminal uses PowerShell by default. Automatic port discovery, worktree cleanup that requires strict process-directory verification, and TUI switching for additional accounts are not yet supported. Unverified worktrees are kept rather than deleted.

Check updates through “업데이트 확인” in the app menu or “설정 → 정보” (settings → about). If your installation format cannot update inside the app, use the latest installer from the website.

Connect Claude or Codex

Taskminal runs the Claude Code or Codex CLI installed on your computer. You need an account and login for the service you choose. Service charges and permissions belong to that account.

  1. Install your chosen CLI and complete its login flow in a regular terminal.
  2. Check that claude or codex starts from your project folder.
  3. Choose that agent when creating a task, or find “새 대화 (Claude)” / “새 대화 (Codex)” in the command palette.
  4. Send a request. Read and answer approval or question cards when they appear.

“CLI 없음” or “로그인 필요”? These mean CLI missing or login required. Confirm the CLI works before reinstalling Taskminal, then use the conversation’s retry/find-again action. “사용량·계정” shows account status.

Manage additional accounts through “사용량·계정”. The default account logs in through its existing CLI; additional accounts use app-specific folders. Saved conversation copies mask secret patterns, while the original messages you send are processed by the agent’s service.

Tasks and working tools

Use tasks for project folders, statuses and notes. Tabs separate working screens; splits put a conversation and shell side by side within a task.

Recover context

Preview text, Markdown, images and PDF files, then attach confirmed files or ranges to a conversation. Search conversation history to find earlier decisions.

Review changes

Read diffs and commit selected changes. GitHub PR/push and worktree tools use the repository’s configured tools and permissions.

Keep pages close

Use the embedded browser to check your development pages. Keep several browser tabs with a task and return to the page you need.

Organize repeated work

Quick commands collect frequent shell commands. Agent workflows, schedules and the result inbox organize repeated requests and their results.

On a narrow window, use “작업 도구 선택” (working tools) or the command palette to reach tools whose individual buttons are hidden.

Data, backups and quitting

Closing the app can leave shells running

A separate guardian keeps shells alive. Reopening the app reconnects to those shells and restores output. To stop everything, choose “셸까지 모두 끝내기” (quit with all shells) in the app menu and review running work before confirming.

Back up workspace state

Use “설정 → 백업 · 되돌리기” to inspect backups, restore state, and export or import tasks and settings. This does not back up your project source files or external service data; manage those separately with Git or other backups.

Local storage and external connections

Tasks, settings and records are stored locally. Claude Code and Codex connect to their own services; the embedded browser, GitHub tools and update checks connect to the services you use. Secret-pattern masking is not complete secret detection. Review logs and screenshots before sharing them.

Troubleshooting

A shell will not connect, or earlier work is missing.

Open “셸 지킴이 보기” in the palette to inspect connections and shells. Try reconnecting first. Restarting the guardian can end existing shells; read the confirmation before proceeding. Do not delete the app data folder as a recovery step.

The agent works in a terminal but not in a conversation.

Check the CLI’s installation and login, then use find-again or retry in the conversation. Your shell and the app may use different environments. Check “사용량·계정” and the error message as well.

An update will not download.

Check “설정 → 정보” and retry. Use “다시 알리기” to undo skipping a version. If it still fails, download the correct OS/chip installer from the website.

What should I include in a bug report?

Include the app version, OS/chip, steps and actual result in a GitHub issue. “오류 기록 열기” in the palette opens error logs. Remove secrets, account details and private paths before sharing.
